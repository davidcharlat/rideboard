A cycling navigation app. <br>
Optimized for France (there altitude data is more accurate thanks to IGN and LidarHD data). <br>
It creates a .fit file that can be uploaded to Strava or exported. 
For the upload to work, if the Strava app is installed on your phone, you must ensure it is not permitted to open compatible web links. <br>
The GPS track remains stored in memory until the "Finir" and then "Exit" buttons are pressed.
